# Note app


> [!TIP]
> **Getting started**
> 
> ```sh
> git clone https://github.com/big-ballsack/note-app # clone the project
> cd note-app # move into it
> pnpm i # install dependencies
> pnpm dev # start the services
> ```

> [!NOTE]
> **Requirements**
>
> - Node.js 26 or newer
> - pnpm 9 or newer
